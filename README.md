# 🚀 ClassBunk v4.0 Pro - Cloud Academic Engine

ClassBunk v4.0 Pro is an advanced, mobile-first cloud academic dashboard designed to streamline university life with high-performance client-side architecture and zero backend overhead. Built with modern glassmorphism styling and a sleek dark theme, it empowers students to effortlessly monitor their attendance percentages, track targets, and log daily classes with intuitive attend and bunk controls.

## ✨ Key Features

* **Precision Attendance Dashboard:** Real-time percentage tracking with quick `+ Attend` and `+ Bunk` action controls and automated target safety meters.
* **Timetable & Holiday Calculator:** Interactive weekly schedule manager with custom day addition and non-lecture academic holiday parsing.
* **Syllabus & Important Topics Hub:** Dynamic course module manager allowing students to add chapters and track exam-critical topics.
* **Live Gemini AI Academic Mentor:** Integrated Google Gemini 1.5 Flash API support with image doubt-scanning capabilities for step-by-step doubt resolution.
* **Client-Side Security Model:** Zero-exposure architecture utilizing browser local storage (`localStorage`) to securely lock user API keys locally.
* **Custom Student Profile Drawer:** Organized line-by-line student profile management featuring theme toggles, course metadata, and data isolation controls.

## 🛠️ Technology Stack
* HTML5 / Vanilla JavaScript (ES6+)
* Tailwind CSS (CDN with Custom Dark Glassmorphic Themes)
* FontAwesome (Icons)
* Google Gemini API (`v1beta/models/gemini-1.5-flash`)

## 🔒 Privacy & Security
ClassBunk v4.0 Pro uses a **User-Key-On-Login** architecture. Your Gemini API key is stored securely inside your browser's local storage and is never exposed or shared publicly in the repository code.
